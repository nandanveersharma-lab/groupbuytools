# Group Buy Tools Platform

A Next.js-based platform providing affordable access to premium SEO, AI, content, design, and marketing tools through group buying. Access enterprise-level software like Ahrefs, Semrush, ChatGPT Plus, Canva Pro, and more at a fraction of retail cost.

## 🚀 Features

- **Unified Dashboard**: Access 100+ premium tools from one centralized platform
- **Category-Based Organization**: Tools organized by function (SEO, AI, Content, Design, etc.)
- **Tool Comparisons**: Side-by-side comparisons of popular tools (Ahrefs vs Semrush, Surfer SEO vs Frase, etc.)
- **Free Utilities**: Includes free PDF tools (merge, split, compress, etc.)
- **Informative Blog**: Guides and articles on digital marketing, SEO tools, and AI workflows
- **Membership Plans**: Transparent pricing with multiple subscription tiers
- **Security Focused**: Session isolation and data protection measures
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **SEO Optimized**: Built with Next.js for optimal performance and search visibility
- **Docker Ready**: Containerized for easy deployment

## 🛠️ Technology Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Content**: MDX/blog system with gray-matter
- **Deployment**: Docker, Vercel-ready
- **Utilities**: PDF-lib, Gray-matter, Class-variance-authority

## 🔧 Getting Started

### Prerequisites

- Node.js 22.0.0 or higher
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/groupbuytools.git
   cd groupbuytools
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Environment Variables

Create a `.env.local` file in the root directory:

```env
# Optional: Add any environment variables here
# Example:
# NEXT_PUBLIC_API_URL=https://api.example.com
```

## 🐳 Docker Deployment

The platform includes a Dockerfile for containerized deployment:

```bash
# Build the Docker image
docker build -t groupbuytools .

# Run the container
docker run -p 3000:3000 groupbuytools
```
